Quickstart

From nothing to a broadcast transaction on your own private chain.

Everything below runs on regtest — a private Bitcoin network where you mine blocks on demand and the coins are worthless. It runs the same consensus code as mainnet, which is what makes it a real test rather than a simulation.

#1. Start the API

powershell
$env:VEYRA_NETWORK = "regtest"
npm run api

It prints a token and, if no mnemonic was supplied, a freshly generated one:

text
Veyra API — regtest
  listening   http://127.0.0.1:3000
  wallet      m/84'/1'/0'  (854f45e9)

  API token (generated, shown once):
    9f2c4e...
The mnemonic is shown once. There is no getMnemonic() and no endpoint that returns it. A copy the wallet can retrieve is a copy an attacker can retrieve.

#2. Make a call

powershell
curl http://127.0.0.1:3000/health

curl -H "Authorization: Bearer <token>" http://127.0.0.1:3000/wallet

#3. Get an address

json
"address": "bcrt1qcl3pgzqcez3wwyp8n4am48qt55y99n6lk439d8",
"path":    "m/84'/1'/0'/0/0"

#4. Fund it and sync

With a regtest node running (see Environments):

powershell
$cli = "C:\Program Files\Bitcoin\daemon\bitcoin-cli.exe"
& $cli -regtest -rpcwallet=veyra-test sendtoaddress <address> 0.01
& $cli -regtest generatetoaddress 1 <any-address>
powershell
curl -X POST -H "Authorization: Bearer <token>" http://127.0.0.1:3000/wallet/sync

#5. Send

Two calls. The first builds and signs; nothing is broadcast.

powershell
curl -X POST http://127.0.0.1:3000/transactions/prepare \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"to":"bcrt1q...","amount":"100000","feeRate":5}'

Read the review, then broadcast that exact transaction by id:

powershell
curl -X POST http://127.0.0.1:3000/transactions/send \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"id":"3f2a..."}'

#6. Or use the interface

powershell
npm run app   # http://127.0.0.1:5173

Paste the token into the connect screen. These docs are served alongside it.
