Veyra Signer

Offline signing. Your seed never leaves this page.

Use this on an offline machine. This page cannot make network requests — its Content-Security-Policy sets connect-src 'none', so there is no channel to send a key out through even if something malicious ran here. That is a strong guarantee against exfiltration and no guarantee against a compromised browser, a malicious extension, or malware that reads memory. An air-gapped machine removes those.
